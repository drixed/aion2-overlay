# Панель «Бой с боссом», русский интерфейс, доработки окна таймеров — дизайн

Дата: 2026-10-07 · Дополняет `2026-10-07-aion2-overlay-design.md` · Одобрено пользователем в чате.

## Что хочет пользователь

- Главное окно как у Abyss DPS Meter: при бое с боссом — шапка «Бой с боссом» + время боя, карточка босса
  (имя, HP `638.8K / 1.20M · 53%`, полоса), «До победы» и «До ярости».
- Ближайший разлом — строкой в самом низу этой панели.
- Настройки приложения на русском.
- Окно таймеров перемещается и меняет размер; надпись «Сервер не определён» не нужна (игрок на одном EU-сервере).

## Решения

### Главное окно — новый стиль, по умолчанию
- Новый компонент `BossPanelPage` (наш файл). Включается настройкой `MainStyle` в `timers-settings.json`
  (`"boss"` по умолчанию; `"upstream"` — вернуть стиль RATmeter). Правка апстрима: +3 строки в `MainDpsPage.razor`.
- Состав сверху вниз: наша шапка (заголовок, время боя, пинг, кнопки RATmeter с русскими подсказками) →
  карточка босса (когда есть цель) → **строки игроков из `MainDpsMinimal` апстрима** (встроены как компонент,
  их собственная шапка скрыта стилем `::deep`) → строка ближайшего разлома/ивента.
  Встраивание вместо копирования: улучшения строк игроков в апстриме приходят сами; если апстрим переименует
  класс шапки — просто появится вторая шапка, ничего не ломается.
- Данные боя — из `CombatSessionManager` апстрима: `GetActiveTargetInfo()` (имя, код, HP), `GetPartyDps()`,
  `GetCombatDuration()`.
- **До победы** = текущее HP ÷ ДПС группы; нет ДПС или HP — «—». Больше 99:59 — «—».
- **До ярости** = таймер ярости − время боя. Таймер: `enrageSeconds[код]` из `schedule.json` (0 — нет ярости),
  иначе для полевых боссов (блок кода принадлежит полевой карте) — нет, для остальных боссов — 5:00
  (так у боссов данжей по metabot.gg). После наступления — «ярость!» красным.
- Заголовок: босс в цели — «Бой с боссом»; обычная цель — её имя; нет цели — «Ожидание боя».

### Русский интерфейс
- Наши окна — сразу на русском.
- Blazor-окна апстрима (настройки и др.): словарь `wwwroot/js/ru.js` (англ. → рус.), применяется к текстам и
  подсказкам (`title`, `placeholder`) при каждом изменении страницы (MutationObserver). Правка апстрима: +1 строка
  в `wwwroot/index.html`. Неизвестная строка остаётся английской. WPF-окна апстрима (история, детали игрока,
  калькулятор, «что нового») — вне рамок.

### Окно таймеров
- Только полевые боссы; разлом/ивенты переезжают в главное окно. Нет таймеров боссов — окно пустое прозрачное
  (не мешает), в режиме настройки — подсказка.
- Размер меняется за уголок (как главное окно апстрима), позиция и размер сохраняются.
- Внизу бледная подсказка «Ctrl+Shift+F9 — переместить / размер» (актуальная клавиша из настроек).
- Безымянные боссы (карта не в таблице) — одной строкой на карту: «Карта 1010 — живы 14, ближайший респ через …».
- «Сервер не определён» убрано. В лог один раз пишется, что известно о сервере персонажа (имя сервера, номер из
  группы) — чтобы позже добавить номера EU-серверов. Номер из данных группы не используется: у соло-игрока его нет,
  и таймеры раскалывались бы при входе в группу.

## Тестирование
- Логика «до победы / до ярости», выбор таймера ярости, разбор `enrageSeconds`, группировка безымянных — xUnit.
- Окна — запуск вживую: скриншот главного окна во время боя (пользователь), окна настроек (перевод), окна
  таймеров (размер, подсказка).

## Вне рамок
- Энергия, еженедельные данжи — отдельная задача после этой.
- Перевод WPF-окон апстрима.
